## 建议新增的最小材料

1. 一段自制工作台录屏：空态、主动合成预览、输入验证、导出结果；持续标明合成样例。
2. 一次真实RDK整合运行记录：版本、配对帧、资源与失败恢复；区分旧服务和新工作台。
3. 一次真实固定机位实验：拟合点与独立控制点分开，报告有效位置、缺失与误差。
4. 底盘、云台、IMU各一段独立运行证据，再做联合任务。过去做过其他硬件与本项目已接入分别介绍。
5. 一个教师确认的授权章节与观察要点，展示能否将教学内容关联到训练证据。
6. 本人和队友的具体分工及实际全程档期。

证据优先增加可复现信息。测试数不等于动作准确率；手机窄屏检查不等于手机视觉实跑；事件计数通过不等于自动识别扣杀。私人素材、原始视频、访问凭据和精确设备地址不进入公开证据附件。
