# 下一阶段任务清单

2026-11-06。任务ID用于协作，不代表功能已实现。当前只读RDK适配与视频观察继续保留，设备地址和原始视频不进入任务正文。

## E0：真实采集与标定前置

- [ ] 在真实RDK验证整合工作台，记录版本、配对帧、断连恢复和运行资源。
- [ ] 审计传感器、曝光、真实时间戳和原服务接口，保持单MIPI所有者。
- [ ] 取得授权场线样本，完成手动交点基线与独立地面控制点测量。
- [ ] 明确线条边缘/中心、像素变换、球场方向及米制有效范围。

验收：真实板端记录与分区测量误差可复查；失效时保留像素观察，不显示未经验证的跑位。

## E1：移动底盘停靠与场地重定位

- [ ] 确认实际平台、SDK、里程计、停止反馈与控制器。
- [ ] 实现移动、停止确认、视觉重定位、允许采集的状态转换。
- [ ] 保存球场—底盘—相机的安装/标定链和版本。
- [ ] 拒绝训练中移动、重复/过期命令；验证断连及人工停止。
- [ ] 记录重复停靠误差、重定位成功率和失败原因。

依赖E0。先证明能稳定停靠观察；自动捡球另有球体定位与回收机构验收。

## E2：云台主动观察与机位复现

- [ ] 确认轴数、角度回读、限位、通信与实际安装关系。
- [ ] 实现预设位、停稳反馈、视觉校正与训练机位锁定。
- [ ] 根据场线覆盖和重投影残差选择补采，保留选位理由。
- [ ] 机位变化时使旧标定失效，支持人工确认降级。
- [ ] 比较主动观察与固定预设位的成功率、部署时间及独立点误差。

依赖E0；可先在固定支架上开发，不必等待底盘。纯旋转不承诺动态球体三维重建。

## E3：球拍IMU采样、同步与候选挥拍

- [ ] 确认采样率、量程、单位、轴定义、安装方向与原始时钟。
- [ ] 保存样本序号、丢包、采样与接收时间，拟合时钟偏移和漂移。
- [ ] 使用独立参考事件检查时间对齐，分别报告时钟和事件误差。
- [ ] 标注真实挥拍、空挥、碰撞和静止，验证误触发与漏检。
- [ ] 候选事件去重并关联视频窗口；允许人工确认和拒判。

时钟与原始数据审计可和E1/E2并行；视觉融合依赖可追溯视频。不可直接把IMU峰值标成触球或扣杀。

## E4：三点训练与实体反馈

- [ ] 用明确标记的人工区域或通过验证的球场区域配置三点任务。
- [ ] 接入实体灯和实际执行反馈，等待到位、回中后推进。
- [ ] 加入可选IMU条件，丢失、过期和设备故障时等待或停止。
- [ ] 连续十轮，专项验证未回中不推进、遮挡不误判和重连不重放命令。
- [ ] 输出规则版本、任务指令、完成证据和训练报告。

可先固定支架＋手动机位完成，再接通E1/E2。控制反馈本地运行，云端只承担允许延迟的分析。

## E5：空间工作台与证据复盘

- [x] P0.2.0重排四工作区、分析导入导出和来源状态；实体训练控制、历史会话管理仍待实现。
- [ ] 统一视频、姿态、IMU与执行器的事件时间线。
- [ ] 点击事件联动视频和对应空间点，显示标定、来源及缺失原因。
- [ ] 分别验证桌面、移动窄屏、键盘操作和真实/回放状态。

各项实现完成后提交变更目的、验证记录和限制；大更新同步README迭代说明。设备接入之前保留任务状态，不创建空驱动冒充实现。
