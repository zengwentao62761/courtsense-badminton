# 采样、标注与评价指南

状态：待执行协议，不含真实样本或精度结果。

## 第一批样本

先记录相机型号/模式、镜头与畸变、分辨率、曝光、实际帧时间、编码、机位高度和朝向、场地条件，以及参与者授权。授权范围需覆盖采集、研究和是否允许公开；不同用途分别确认。私人原视频留本地或经授权存储，普通Git只保存规范和可公开统计。

采样从固定机位、单人、完整可见的训练区域开始，覆盖近中远站位、停留、慢移动、跳起、遮挡和相机被轻触后的重标定。控制点现场独立测量；拟合点与验收点分开。

球迹样本覆盖白色背景、灯具、拖影、出画和遮挡。动作样本需同时有扣杀、高远、吊球和挥空，避免只采“容易识别的扣杀”。先小批双人复标，处理分歧后再扩大采集。

## 标注对象

- 场线：语义、端点/交点、遮挡、使用内外边或中心的规则。
- 人：轨迹ID、可信支撑脚/地面代理、跳起/遮挡、无法判断。
- 球：逐帧可见点、点定义、出画与缺失；补全不作为真值。
- 事件：一次击球的时间区间、类别、球员、证据、分歧/确认状态。
- 手/拍：单独定义关键点和视角适用范围，不能仅复用COCO17评分。

## 验收表

| 模块 | 必须同时报告 | 不能替代验收的现象 |
| --- | --- | --- |
| 标定/定位 | 独立控制点米制误差、中位/P95、近中远分布、可用覆盖率 | 拟合角点重投影很小 |
| 人体跟踪 | 身份切换、丢失、遮挡恢复，单人与多人分别验证 | 人体框一直存在 |
| 击球/扣杀 | 预先固定时间匹配窗口，一对一事件匹配后的precision/recall/F1、计数误差与拒判率 | 逐帧类别准确率 |
| 球体检测 | 可见帧漏检/误检、定位误差、轨迹中断；输入分辨率固定 | 展示平滑曲线 |
| 球速 | 独立参考、时间同步、误差分布、有效片段比例与失败 | 单目拟合残差很小 |
| 动作评价 | 教练标准、标注一致性、机位适用、独立测试与分歧 | 总分有小数、分类概率很高 |
| 端云 | 采集至展示P50/P95、时钟域、队列/丢帧/断网恢复 | 模型单次推理时间 |
