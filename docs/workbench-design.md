# 具身训练工作台设计

2026-11-06 · 待实现设计。当前UI仍为P0.1.0视频观察台，下面的控制、同步时间线和真实跑位功能尚未接入。

## 信息结构

左侧入口为场地准备、实时训练、动作复盘、历史与设备。顶部显示当前训练目标及可开始的条件。中央保留较大视频区，支持与3D/俯视球场切换；右侧显示当前任务、完成条件、证据和下一步练习。底部采用同一事件时间线，关联视频、骨架、IMU和设备执行反馈。

移动底盘、云台、球拍IMU分别显示未配置、待接入、就绪、执行中或故障；状态只由实际设备反馈产生。设备详情可折叠，运动者首先看到是否能开始训练及需要处理的事项。

## 3D视图的实际用途

场地准备时显示已验证场线、待补采区域、相机视锥以及底盘/云台的实际状态。训练时显示有效地面位置、当前目标与完成记录；复盘时点击位置或事件跳到对应片段。只有几何模板时保留“场地示意”，像素踝点只画在图像坐标中。

不补画未知高度、三维人体或球迹。缺失轨迹断线，候选事件空心标记，遮挡区间加文字说明。数据质量与动作表现分开；评价卡回答观察、依据、下一项练习，参考不足就显示缺少什么。

## 视觉方向与地瓜元素

使用浅灰工作底色、石墨文字、绿色球场，原创橙色用于当前任务及设备执行。色彩提案：#F2F4F6、#15212B、#1C7560、#F47E32；这些不是官方品牌色值。避免相同数字卡片挤占视频与任务空间。

设备页突出实际RDK型号、安装示意及采集链路。官方Logo和设备图需核对来源与使用条件后采用；原创图标与“影子教练”视觉单独标明自设计。保持羽境主体名称，不暗示官方认证或联合出品。

## 迁移与验收

先重排现有真实视频、二维角和报告入口；再加入有共同时间语义的事件复盘；最后接入三设备准备流程及实体训练任务。每阶段单独验证，不先展示没有数据支持的在线设备动画。

关键交互验收：点击事件能定位同一片段；机位失效时米制图层停止；未接IMU不能出现真实IMU曲线；断连不伪装继续训练；回放和实时模式持续可辨；窄屏与键盘可访问。用户当前暂停按钮仍只暂停页面刷新，不能改称设备停止。
