# 羽境 CourtSense｜报名填写稿

项目名称：羽境 CourtSense——基于球场线约束建图的人—球—拍协同分析与具身训练系统。

以下视觉分析新功能均为计划。已有成果来自原RDK X5羽毛球视觉项目；新仓库已公开报名资料、设计与名义球场示意工具，尚未完成真实视频算法集成或现场验收。

## 你做过什么项目？（3000字以内）

目前已有一个基于RDK X5和单目MIPI相机的羽毛球视觉训练原型，完成了板端实时人体姿态服务部署、画面方向校正、人体骨架与17点关键点显示，以及二维关节角、运行状态、训练记录和标准球场展示的工作台。最近一次短时验证约13 FPS，已通过VS Code Remote-SSH实际打开板端代码并运行任务，使用Git与Codeup记录迭代和部署过程。

还使用公开羽毛球比赛数据完成了8组三帧样本、2次优化器更新的小规模QLoRA训练试跑，完成适配器合并、GGUF量化和X5 CPU实际推理。这部分已跑通实验链路，但分类和速度尚不足以支持可靠实时评分，未把训练loss或模型能运行当作准确率结论。

原项目当前主要具备人体感知和训练数据展示能力。球场自动匹配、可靠跑位图、扣杀统计、羽毛球三维轨迹和真实球速均尚未完成。因此，本次希望以已有硬件和工程经验为基础，独立推进“羽境CourtSense”，重点解决低成本球场坐标建模和人—球—拍时空数据对齐问题，并把重计算模型放在云端。

## 这次准备做什么项目？（6000字以内）

项目名称：羽境CourtSense——让真实羽毛球场成为能理解训练过程的空间。

希望基于RDK X5、单目MIPI相机与云端视觉分析，建立一个低成本的人—球—拍协同训练系统：利用球场本身的边界线、发球线及交点建立可复核的球场坐标系，将球员落脚位置、移动轨迹、击球事件及羽毛球轨迹关联到同一时间轴，逐步形成扣杀次数、跑位点位图、活动热区、回位表现和关键片段回放。

建图不直接套用通用SLAM。固定机位优先用镜头标定、球场线拓扑匹配和已知尺寸恢复平面映射，并持续检查线条重投影和机位漂移；先允许人工确认关键交点，再发展自动匹配。对脚离地、遮挡、球员身份不确定或标定失效的情况保留缺失与置信度，不能用平滑轨迹伪装真实测量。

羽毛球是高速小目标，拟采用多帧检测与轨迹关联，结合球员动作、击球事件及球场几何逐步验证扣杀识别。球体像素轨迹、受约束的三维估计和真实球速分别验证，不把地面单应变换直接用于空中羽毛球，也不预先承诺厘米级位置或专业测速精度。后续增加球拍与手部关键点，研究拍柄和前臂的可见夹角、动作阶段和教练标注之间的关系，再逐步形成有依据的技术动作评价。

端侧重点承担稳定采集、原始时间戳、现有人体感知、数据缓存及必要的质量检查；球体和球拍检测、时序模型、复杂轨迹重建与报告生成优先放云端，暂不继续向X5部署额外大模型。高帧率与短曝光能力、上传带宽和端云延迟先实测，网络较差时保存原始素材，训练后补充分析。

具身交互作为后续扩展：根据已验证的跑位和回位信息控制声光任务或固定柔性靶装置，并用实际到位或触靶反馈决定下一轮练习。此前提出的假动作对抗也可作为独立实验模式，重点形成“感知—空间理解—训练决策—物理反馈”的闭环，而不只增加屏幕图表。

已有基础是X5人体姿态服务、工作台和远程开发流程。本次优先完成球场人工确认标定、单人可信位置分布、数据采集与云端离线分析链路，再逐级接入击球/扣杀事件、球体轨迹、条件满足时的速度估计和动作评分。第一阶段不把全部复杂指标同时作为必交能力，所有结果保留来源、版本和可回看证据。

## 你需要哪些硬件或技术支持？（3000字以内）

自带硬件：RDK X5开发板、单目MIPI相机和开发电脑。

希望获得的硬件支持：固定相机支架及安装材料1套、镜头标定板和地面测量材料1套、稳定供电与本地存储支持。如果现有相机的分辨率、实际采集帧率或曝光不足以记录高速羽毛球，希望借测一套兼容RDK的低成本高帧率短曝光相机，用于比较与选型，不以深度相机作为前提。云端分析希望获得GPU计算和存储额度，具体规格根据实测吞吐确定。

具身扩展按进度申请MCU、声光提示器件或单轴柔性靶机构及位置/触靶传感器，初期不要求移动底盘、机械臂或自动发球机。

希望获得的技术支持：球场线检测与相机标定、球员落脚定位和身份跟踪、高速小目标时序检测、单目物理约束轨迹估计、端云视频传输与时间对齐，以及羽毛球教练参与动作类别和评价标准标注。也希望获得真实球场测试机会及可用于研究的合规样本。
