# CourtSense 项目基础完善计划

目标：完善公开仓库阅读与协作入口，并提供无需模型或设备的球场几何示意生成示例。依据README与technical-plan；不连接板卡，不开展真实定位。

技术：Python 3.10+标准库、unittest、SVG、GitHub Actions。模板为名义线位置示意，不能直接作为精确标定控制点；不生成虚构球员轨迹、球速或评分。

任务：

1. 先写模板几何/语义、可解析SVG与拒绝覆盖的测试，确认缺少实现时失败。
2. 实现名义球场线模板与CLI，生成带状态标识的SVG预览和JSON。
3. 增加坐标/时间/事件契约、采样标注、评价、贡献及Issue规范，维护README和交接。
4. 本地验证示例、测试与文档链接；公开预览仅含几何示意。
5. 提交、推送并核对远程内容。Actions结果单独查询，不用本地通过代替远程通过。

执行记录：上述工具、测试与规范已完成；本地3项检查通过。发布时GitHub因缺少workflow权限拒绝了活动CI配置，改为docs/ci中的待启用模板。远程CI未验证。

检查重点：单双打边线区别、发球中线只在发球区、无轨迹伪装实测、输出不覆盖已有目录、日期和能力状态一致。
