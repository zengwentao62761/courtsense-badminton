# 阶段路线与验收

所有阶段尚未实施。按依赖推进，报名说明不能当作已交付清单。

| 阶段 | 输出 | 进入下一阶段的证据 |
| --- | --- | --- |
| P0.0 当前 | 独立仓库、报名答案、方案与交接 | 文件与链接核对；不包含运行应用 |
| P0.1 | 相机模式审计、带时间戳的小批真实样本及标注规范 | 原帧/PTS可追溯，帧率、曝光、丢帧及授权情况有记录 |
| P0.2 | 手动确认场线标定、单人球场点位与停留图 | 独立测量控制点的分区误差、跳起与遮挡缺失策略通过 |
| P0.3 | 云端二维羽毛球轨迹与击球候选，人工确认扣杀 | 按场次隔离测试，报告事件计数误差、球迹检测与中断 |
| P0.4 | 多源融合扣杀统计、准实时工作台 | 检查重复事件、身份与时间对齐，报告端到端延迟和失败 |
| P0.5 研究 | 受约束三维轨迹及速度估计 | 独立参考与误差分析；不满足则不发布km/h |
| P0.6 研究 | 球拍/手部阶段指标与教练评价 | 关键点、视角、标注一致性与独立评分参考 |
| P0.7 可选 | 声光或固定柔性靶实体反馈 | 执行到位、故障停止、过期数据处理及实际反馈验收 |

每阶段交付README版本说明、变更目的、数据/标定/模型版本、真实验证、未解决项及Git提交。当前不承诺精度、球速上限、人数覆盖或端云实时帧率。

验证分组按比赛/球场/机位隔离，不能把同段视频相邻帧随机拆分后声称泛化。原始观察、算法估计、人工标签及合成样例分开保存。未知情况保留，不用插值补齐测试真值。
