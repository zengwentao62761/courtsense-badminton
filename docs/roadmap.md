# 阶段路线与验收

更新：2026-11-06，P0.2.0。已实现新版UI与五项手工/导入分析开发基础；三设备仍未接入。

| 阶段 | 输出 | 进入下一阶段的证据 |
| --- | --- | --- |
| P0.0 / P0.0.1 已完成 | 独立文档、名义球场几何与工程基础 | 文件与几何检查；不是现场标定 |
| P0.1.0 已实现、RDK整体验收待完成 | 姿态基础、只读适配、视频观察、3D示意及报告 | 历史28项测试与真实视频100帧CPU试跑；不能替代板端验收 |
| P0.2.0 当前实现 | 四工作区、手动点对、米制接地点、导入球迹/扣杀/条件化速度 | 39项测试及合成浏览器验证；真实自动识别与精度待补 |
| P0.1.1 设计基线 | 三设备路线、状态流程、接口约定、任务和UI方案 | 文档一致性与链接检查；没有三设备实跑结论 |
| 下一步 E0 | 真实RDK采集审计、授权样本、人工确认标定基线 | 原始时间戳、独立控制点与错误情况可复查 |
| E1 移动底盘 | 停靠、停止确认、视觉重定位和训练互锁 | 重复停靠与失联实验；训练中不移动 |
| E2 云台 | 主动观察、机位复现、停稳锁定和标定失效处理 | 与固定预设位的成功率、耗时及独立点误差比较 |
| E3 球拍 IMU | 原始采样、时钟偏移/漂移、候选挥拍与视频关联 | 同步与事件误差分别测量；空挥负样本、漏检与去重 |
| E4 实体训练闭环 | 三点提示、到位与回中判断、可选IMU条件 | 连续十轮；未回中不推进，遮挡等待，故障停止 |
| E5 证据工作台 | 视频/事件/空间联动及设备准备流程 | 事件跳转、来源与模式、断连、窄屏与键盘验证 |
| 分析后续 | 米制跑位与停留图、云端二维球迹、人工复核扣杀 | 按场次隔离测试；独立定位、事件与球迹参考 |
| 研究后续 | 受约束三维轨迹/球速、球拍手腕评价、训练后捡球 | 可辨识性、独立测量、教练参考或回收机构专项验收 |

E1/E2依赖E0标定基础；E2可先固定支架开发。E3采样审计可并行，融合依赖可追溯视频。E4可先用固定支架与人工图像区域完成，再加入底盘和云台。三设备都是关键扩展，依赖顺序不降低其优先级。

实际工作项见[任务清单](extension-tasks.md)，设备链路见[三设备设计](embodied-expansion.md)。现场先恢复真实RDK采集与三点任务，再接设备增强；完整球场不具备时明确标注小场演示，回放不作为实时实体闭环证据。

每阶段记录目的、数据/标定/模型/控制规则版本、真实验证、未解决项及Git提交，大更新维护README。原始观察、估计、人工标签与合成样例分别保存；验证按场次、机位与人员隔离。
